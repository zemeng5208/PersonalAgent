# PersonalAgent 产品需求文档

版本：0.1 · 日期：2026-09-05 · 状态：需求基线草案

产品负责人：用户 · 底座/公共协议/集成：`goo122`（A） · 桌面与执行：`zemeng`（B） · 具体分工见 [模块分工](MODULE_ASSIGNMENTS.md)

## 1. 产品目标与已确认方向

构建 Windows 私人 Agent 助理，具备 Jarvis 式常驻交互：平时呈现动态悬浮球，鼠标靠近展开面板，通过专门按钮进入完整管理后台。

用户表达目标后，系统选择工具或专业 Agent，完成信息获取、判断、受控行动和结果反馈。以盘古 API 作为主推理 Agent，其他模型辅助。默认采用主动提示与有限自动执行。

明确纳入产品方向：Obsidian、日程、研究、软件操作、编程、语音、微信与其他可用社交平台、邮件、通知、博主订阅、实时信息、天气、MCP、Skills、持续学习，以及 TraceGuard 能力。

本项目用于华为 ICT 创新赛准备；确切届次、提交日期、评分标准与技术使用要求尚未核验。API 接通与满足参赛要求分别验收。

## 2. 范围与证据状态

- 已确认：Windows 优先、悬浮球交互、盘古主导、多模型辅助、上述能力方向。
- 建议方案：具体技术栈、模块拆分、交互延迟、实现优先级；见架构与计划。
- 待验证：盘古可用部署与能力、各平台权限和接入方式、语音供应商、具体 Windows 兼容范围。
- 当前实现：MOD-01/02/03 已评审并集成；MOD-25 天气连接器源码已通过 PR #4 合并并完成条件式真实读回，但地点正确性、权限宿主和 Runtime 根装配尚未完成。尚无桌面、模型或完整真实平台闭环，需求完成状态见 ROADMAP。

“所有可用平台”表示连接器可持续扩展，不承诺全部平台均能完整读写。不得以 UI 自动化作为绕过平台限制的手段。

## 3. 用户与核心体验

首要用户是希望通过自然语言管理个人知识、时间、信息和电脑任务的 Windows 用户。日常无需理解 Agent、MCP 或模型配置；高级能力在后台可查看、配置和停用。

关键用户旅程：

1. 靠近悬浮球，语音要求“查一下明天天气，结合日程提醒我”。系统提供有时间与来源的信息，必要时创建提醒。
2. 要求整理指定 Obsidian 笔记。系统检索、形成修改方案，在授权范围内写入并返回位置与变更摘要。
3. 收到订阅更新或邮件。系统去重并按重要性汇总，不把每次更新都弹成打扰。
4. 要求诊断电脑变慢。TraceGuard 提供真实观测，盘古区分事实与推测；受控操作后回读验证。
5. 要求协助修改项目代码。系统限制工作区、报告改动和实际验证，不自动发布。

## 4. 优先级定义

- P0：首次可用版本必须具备的核心闭环。
- P1：核心稳定后补齐的主要功能，仍属于产品范围。
- P2：持续扩展或依赖额外验证的能力，不以首版承诺交付。

优先级是建议交付顺序，不代表否定用户要求。具体范围变更由产品负责人确认。

| PA-015 | 统一通知与订阅 | P1 | 至少一个真实订阅源增量更新、去重和汇总；支持安静时段、暂停和频率设置 |

## 6. 交互要求

- 悬浮球动画反映真实状态，不展示虚假进度；待机低干扰。
- 靠近只预览，点击、输入或语音后固定；离开延迟收起，拖动不触发。
- 多屏和缩放变化后仍在可见区域；全屏隐藏与开机启动可配置。
- 后台提供工具来源、账号健康、任务历史、授权、记忆纠正和停止入口。
- 默认中文。其他语言暂不作为首版完成门槛。
- 配色和最终视觉稿尚未确认；实际设计遵循用户指定的 Open Design 位置，不擅自新建平行设计项目。

## 7. 主动性与授权

- 已授权只读查询、提醒和明确规则可自动运行。
- 写入指定笔记、归档指定邮件等需要动作范围授权；持续授权绑定对象、动作、期限和额度。
- 发送消息、删除、邀请、发布或系统调整不得由模糊的“全权管理”推导无限权限。
- 默认不主动采集密码、Cookie 或私人内容；连接平台采用受支持的认证流程。
- TraceGuard 保留普通用户权限边界，不申请提权或绕过关键系统保护。
- 撤销授权阻止后续动作；已完成且不可撤销的外部操作如实说明。

## 8. 非功能要求

| 方面 | 设计目标 / 验收方式 |
| --- | --- |
| 性能 | 悬浮入口不被网络推理阻塞；暂定交互反馈 P95 小于 200ms，正式阈值随基准机器确认 |
| 资源 | 待机不持续调用模型、截图或高频轮询；基准测试记录 CPU、内存与动画负载后确定预算 |
| 可靠性 | 任务持久化，写入去重，异常退出可恢复；模拟不确定写入结果验证不重复发送 |
| 隐私 | 最小数据上传、密钥隔离、日志脱敏；用户可查看和删除记忆与索引 |
| 可观测性 | 任务、工具、模型请求关联；记录摘要依据与实际结果，不要求保存模型内部思维链 |
| 可用性 | 展示断网、账号过期、平台不支持和模型失败；不得静默伪造降级结果 |
| 分发 | 必要运行文件自包含；干净环境验证安装、运行、卸载和用户数据处理 |

上述性能数值为目标而非已测结果。首版仅在验收时记录的 Windows 环境声明支持，Windows 10/11 全覆盖需分别验证。

## 9. 首版完成与暂不承诺

首版需满足所有 P0，并展示“语音提出需求 → 盘古决策 → 工具执行 → 结果验证 → 可追溯反馈”。各 P0 不可因演示只覆盖一条路径而被标为全部完成。

暂不承诺：关机后持续执行、全部社交平台完整读写、任意软件无条件自动化、无限自主执行、盘古参数自训练。

## 10. 待决事项

- 语音/嵌入/视觉模型供应商、数据出机边界。
- 基准电脑、资源预算、正式视觉与兼容范围。

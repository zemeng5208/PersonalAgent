# 本地流程学习使用说明

适用：`huawei_ict_agentarts` 的本地参考摘要流程。当前只支持固定的参考文件读取与摘要，不代表模型训练或云端 AgentArts Workflow。首次操作建议使用公开测试文件。私人 Vault 的逐条记忆确认是另一个入口。

## 1. 准备参考文件

1. 在独立文件夹中准备文本或 Markdown，例如 `reference.md`。原文件只读，不会因学习流程删除而被删除。
2. 打开设置中的工作区权限，使用原生选择器选择该文件夹和可信 Node。若提示需重启，先重启。
3. 点击 **授权本地读取及所选权限**。只做本地摘要时，云端发送、写入、受限命令、项目构建复选框保持未勾选。
4. 在 **插件** 中点击 **连接只读服务**，看到 `connected` 后点击 **启用参考摘要**，看到 `ready`。

重启保留目录配置，不保留本次会话授权；再次执行前需重新授权本地读取并连接服务。不要为本地流程勾选云端发送。

## 2. 建立并验证一个版本

在 **记忆 → 流程学习** 中填写：

| 字段 | 示例与含义 |
| --- | --- |
| 流程 ID | `reference-review`，同一个流程所有版本共用此 ID |
| 参考文件相对路径 | `reference.md`，相对于已选择的参考文件夹 |
| 流程说明 | 一句话说明用途；新建候选使用当前输入框中的内容 |
| 查看版本 | `1`，读取、验证和启用针对这个版本；执行针对当前启用版本 |

1. 点击 **生成候选**：创建一个不可变版本，当前启用版本不改变。
2. 点击 **提交验证任务**：出现“任务已受理”只代表已提交，尚未验证成功。
3. 点击 **读回验证**：若任务仍在运行或等待审批，先处理任务，再读回；只有显示 **验证通过** 才能启用。失败的版本不可启用。
4. 点击 **确认启用此版本**，核对原生对话框的流程 ID 和版本。选择 **取消** 不会改变当前启用版本。
5. 确认后核对 **当前启用：v1**，再点击 **运行已启用版本**。任务受理不代表执行成功，最终状态以 Runtime 任务读回为准。

## 3. 新版本与回退

- 新版本：保留流程 ID，填写新参考文件路径和说明，再生成候选、验证并确认启用。生成 v2 本身不会替换 v1。
- 回退：将 **查看版本** 改为已验证旧版本，如 `1`，点击 **读取版本**，再点击 **确认启用此版本**。确认后检查 **当前启用**。
- 读取旧版本不会自动改写“参考文件相对路径”和“流程说明”的草稿。再次生成候选前核对这两个输入。
- 读取不存在的版本会清除旧的已选版本，不能继续启用或删除旧选择。

## 4. 停止与删除

**停止或核实此任务** 绑定界面记录的原任务 ID、流程 ID 和版本。修改输入框不会改成停止另一条任务。

- “停止请求已受理，尚未确认停止”表示 Runtime 已记录取消请求，执行可能还未结束。再次点击同一按钮读回。
- 只有读回 **已取消、失败或已完成** 的终态后，界面才移除该任务的停止入口。
- 删除前，先用 **读取版本** 读取目标流程的最新版本；删除以最新版本为基线，旧版本请求会被拒绝。
- **删除流程** 的原生确认删除该流程全部版本、验证引用和激活历史，并请求停止其未完成任务。选择 **取消** 不删除。
- 删除保留无正文的防重用收据，同一流程 ID 不用于重新创建。需要新流程时使用新 ID。

删除保障限定为应用学习数据库；参考原文件、独立外部备份，以及 Runtime 既有任务执行记录不在这条学习删除保证内。不要将“流程已删除”理解为所有系统副本均已抹除。

## 状态速查

| 状态 | 表示什么 | 下一步 |
| --- | --- | --- |
| 待验证 | 候选已保存，无成功验证 | 提交验证任务并读回 |
| 验证通过 | 精确版本有 Runtime 验证证据 | 单独确认启用 |
| 验证失败 | 验证未通过，不可启用 | 查看失败原因，修正后创建新版本 |
| 当前启用：vN | 后续运行使用这个版本 | 可执行或回退 |
| 尚未确认停止 | 取消已受理，未读回终态 | 再次核实原任务 |
| 所选版本不存在 | 请求的版本已删除或从未存在 | 核对流程 ID、版本及当前启用状态 |

原生本地成功不证明真实云端部署或云端记忆消费。云端验收目前按用户要求暂缓。

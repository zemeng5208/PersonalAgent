# PersonalAgent


PersonalAgent 是一个用于协作开发的个人智能助手项目。

## 项目状态

项目处于初始化阶段，当前只包含协作基础设施和目录骨架。

## 目录约定

```text
.
├── docs/       # 设计文档、决策记录和接口说明
├── scripts/    # 本地开发和维护脚本
├── src/        # 应用源代码
├── tests/      # 自动化测试
├── .editorconfig
├── .gitignore
└── CONTRIBUTING.md
```

## 开始开发

1. 克隆仓库并创建自己的功能分支。
2. 在提交代码前补充或更新对应测试和文档。
3. 按 `CONTRIBUTING.md` 的约定提交 Pull Request。

具体运行方式会在技术栈确定后补充到这里。

## 协作原则

- 一个分支只解决一个清晰的问题。
- 不提交密钥、个人配置、构建产物或本地缓存。
- 影响使用方式的改动必须同步更新文档。
- 合并前确保相关检查在本地通过。

多人协作项目。

## 开发

当前仓库已初始化为 Git 项目，默认分支为 `main`。后续协作请通过分支和 Pull Request 进行。

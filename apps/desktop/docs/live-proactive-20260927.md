## 本轮需求

- SIS 麦克风入口只听写到可编辑输入；文字发送保持文字回答。
- 波形按钮与可配置快捷键控制原生 Live；千问负责听说，工作请求复用 AgentArts 主智能体与本地执行体系。
- Live 双方发言进入正式主对话，和文字按时间展示、复制、定位，关闭重开及应用重启后保留；不得伪造 Runtime 任务。
- 普通回答后继续聆听，异常续连需真实状态；停止播放、关闭 Live 与取消业务任务保持独立语义。
- 主动提醒从真实观察或事实变化产生，经目标影响判断、去重、分析与必要计划修复，实际执行仍由 Policy 授权。
- 邮件、订阅、社交变化通过现有公开连接器形成带来源的事实；Laya 在已授权范围内处理简单低风险自主分类与决策，Agent 汇总重点、结果和待处理事项。保持 Potatos498 模块所有权。

千封邮件等高批量场景尚无吞吐与时延证据，不承诺容量或完成速度；连接器真实读回、分类质量、影响传播和副作用授权须分别验证。

## 主动提醒界面与授权范围

“电脑操控”页提供监控和云分析开关。监控仅读 CPU / 内存，每 30 秒采样一次，
本次应用会话最长 8 小时；关闭或应用退出立即撤销，重启后不恢复开关。
云分析默认关闭；显式启用后，持续 CPU / 内存压力触发 AgentArts 自动分析，用户也可手动请求。
云端只接收最小脱敏指标：CPU / 内存占用比例、来源及采样时间。
事实变化的内容投影需要对应授权，不能沿用指标许可发送私人邮件或社交正文。

UI 消费 `snapshot.proactive`，设置调用 `proactive.configure({enabled, cloudAnalysis})`，
手动分析调用 `proactive.analyze({id})`。建议按 ID 去重并读回实际任务状态；空态不生成建议，
不抢占输入或打开音频。保存配置不等于获得系统调整授权，分析完成不等于本地执行完成。

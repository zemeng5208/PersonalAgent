# AgentArts 安全配置入口

## 2026-10-13 WSS 与独立镜像凭据配置

“设置 → 模型 → AgentArts 主智能体”新增 WSS 地址、独立镜像访问令牌和显式 HTTPS 备用开关。
新配置表单默认 WSS，备用默认关闭；已有三字段记录继续使用原 HTTPS / 宿主环境配置，
不会猜测 WSS 公开地址或自动迁移。选择 WSS 后填写当前部署确认过的精确地址。

| 设置 | 当前自有镜像的填写方式 |
| --- | --- |
| 网关地址 | Huawei Runtime 公布的 HTTPS 网关根地址 |
| 运行时实例名称 | 当前部署实例名称；实例名与 WSS 路径必须一致 |
| 平台 Authorization | AgentIdentity 入站 API Key 对应的完整 `Bearer …` 值 |
| WSS 地址 | 同一网关的 `wss://网关/runtimes/实例名称/invocations/ws`；只接受明确填写的精确路径，不接受查询或片段 |
| 独立镜像访问令牌 | 云端 `PA_AGENT_WSS_AUTH_TOKEN` 的原始令牌，不加 `Bearer` |
| HTTPS 备用 | 显式勾选后才启用；只允许未发送调用时切换，结果未知仍停止重发 |

两种凭据随配置一起由 Electron safeStorage 加密；Renderer 快照只返回公开连接选项，
密码输入在保存提交和撤销时立即清空。空凭据只能沿用同一网关和实例；更换目标必须重新填写。
同目标的凭据轮换可供后续调用读取。目标、WSS 路径、连接方式或备用策略改变后，旧 Runtime
不能继续读取新配置凭据，保存结果提示重启。撤销失败会明确报错并立即关闭内存凭据入口，
仍需解决本机存储问题并重试删除，不能把磁盘删除失败报告为已永久撤销。

未保存新传输配置时仍支持 `PA_AGENTARTS_TRANSPORT`、`PA_AGENTARTS_WSS_URL`、
`PA_AGENTARTS_APP_TOKEN`、`PA_AGENTARTS_HTTPS_FALLBACK` 宿主环境入口。
显式保存传输配置后，以加密记录为准，不会被旧进程环境覆盖。旧格式无需数据库迁移。

2026-10-13 原始提交曾完成加密适配读回、迁移、凭据轮换与目标隔离、非法输入及撤销失败等定向测试，
以及恢复配置后 Runtime/Coordination 消费 WSS 的合成检查。设置组件与生产样式也曾在合成页面检查。
这些是原始提交的历史证据；当前头新增保存传输接线、绑定保护与样式回归断言后，尚未独立重新执行定向测试，
须以当前头 CI 为准。没有读取真实凭据或连接 Huawei。本次入口补齐不代表桌面到真实云端、
完整自主修复或各业务工具已经验收；既有真实镜像文件读取证据仍按原记录单独计算。

Competition 模式的“设置 → 模型”可配置网关地址、运行时实例名称、控制台 API 示例中的完整 Authorization 值。可信主进程验证目标、使用 Electron safeStorage 加密保存全部配置；快照只返回配置状态和公开端点，保存后清空输入框。缺少有效网关与实例时延后 Runtime 初始化；已有真实目标但缺凭据时可装配本地 Runtime 与独立的 Live/听写服务，AgentArts 仍明确显示未配置，发请求前仍必须取得有效凭据。首次保存后立即装配，同一实例更新凭据无需重启。更换目标或初始化部分失败后需重启，避免重复打开数据库和服务。既有环境变量仍可作为未保存设置时的兼容入口。

凭据仅可沿用同一网关与运行时，目标改变必须重新填写。旧 Runtime 在目标改变后不能读取新目标凭据。网关限定 HTTPS 华为 AgentArts 域，拒绝用户信息、非默认端口、查询和片段；控制字符凭据拒绝。当前不提供自动创建密钥或账号功能。

配置文件位于 Electron userData，不提交 Git。未配置时显示设置入口，不静默回退 Local。配置保存、宿主构建或 Fake 检查不代表实际云端连接完成。

早期提交的历史验证：宿主定向测试通过，覆盖加密存储适配、快照不泄漏、进程重建读取、目标切换凭据隔离和控制字符拒绝；JS 语法检查通过；实际设置组件用合成状态做过浏览器布局读回。尚未保存新的真实凭据或执行本轮真实 AgentArts 调用。

缺凭据启动分支另以真实本地 Runtime 和合成配置核对：Live 网关可构造，AgentArts 任务失败且 HTTP 调用次数为零，配置文件未被创建或覆盖。这不代表真实麦克风或语音连接已经验收。
